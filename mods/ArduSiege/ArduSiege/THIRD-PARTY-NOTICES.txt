ArduSiege - third-party notices
==================================

This mod embeds a trimmed build of MoonSharp (http://www.moonsharp.org),
a Lua interpreter for .NET.

  Upstream project : https://github.com/moonsharp-devs/moonsharp
  Version          : v2.0.0.0 (commit 3154416e535ab96c0d52bf12e3e472985a1532f4)
  License          : BSD 2-Clause License (full text below)
  Modifications    : the optional CLR interop layer (System.Reflection based)
                     was removed to comply with the Besiege mod loader's
                     security scanner; an internally generated module
                     registration file replaces the reflection-based one.
                     Source of the trimmed build:
                     third-party/moonsharp-trimmed/ in the project repository.

This product also draws design inspiration from the "Lua Scripting Mod" by
ilyshk4 (Steam Workshop 2383785201) - no code was copied.
